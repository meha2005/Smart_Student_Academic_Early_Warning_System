# Student Performance Prediction and Early Warning System

## Project Overview
The Student Performance Prediction and Early Warning System is a Machine Learning mini-project designed to analyze student academic performance and identify students who may be at risk of poor academic outcomes.

The system uses student-related factors such as study hours, attendance, parental involvement, sleep hours, and previous academic performance to understand the factors affecting student success.

## Objectives
- Analyze factors affecting student performance.
- Perform Exploratory Data Analysis (EDA).
- Apply Machine Learning algorithms.
- Predict student academic performance.
- Identify students who may need additional academic support.

## Dataset
**Dataset Name:** Student Performance Factors

**Source:** Kaggle

**File:** `StudentPerformanceFactors.csv`

The dataset contains information about student study habits, attendance, parental involvement, and other factors influencing academic performance.
